# Descripción
Este es un proyecto de alumnos de segundo curso de Ingeniería Informática para la asignatura de Ingeniería del Software I.
Tiene una finalidad puramente educativa.
En él se pretende desarrollar una aplicación de apuestas sin dinero real en juego como proyecto ligado a la ya mencionada asignatura.
Este proyecto se ha realizado mediante la metodología agile Scrum.
