# 0001 · Stack tecnológico

**Estado:** PROPUESTA, pendiente de decidir en equipo.

## Contexto
Somos 5 personas con distinto nivel en desarrollo web. Necesitamos algo que todos puedan aprender rápido, que tenga mucha documentación y que se pueda desplegar gratis.
Antes de decidir, comprobar si la asignatura exige algún lenguaje o herramienta (p. ej. Java, UML con una herramienta concreta).

## Opciones
| Opción | Frontend | Backend | BD | A favor | En contra |
|---|---|---|---|---|---|
| A | React (Vite) | Node.js + Express | PostgreSQL/SQLite | Un solo lenguaje (JS/TS) en todo el proyecto, enorme comunidad | Hay que aprender React |
| B | Thymeleaf o React | Java + Spring Boot | PostgreSQL/H2 | Java ya conocido de la carrera, encaja con UML y diseño OO | Más configuración inicial |
| C | Plantillas Django | Python + Django | SQLite/PostgreSQL | Login y panel de admin incluidos (el admin cubre la HU-07 casi gratis) | Menos separación frontend/backend |

## Recomendación
Si el equipo domina Java, la **B**. Si no, la **C**, que es la más rápida para tener login y admin funcionando en el Sprint 1.
