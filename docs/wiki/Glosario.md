# Glosario

| Término | Significado |
|---|---|
| 1X2 | Apuesta al resultado: 1 gana el local, X empate, 2 gana el visitante |
| API | Servicio al que otro programa pide datos por Internet (aquí, football-data.org) |
| BCrypt | Algoritmo para cifrar contraseñas de forma que no se puedan recuperar |
| Boleto | Lista de selecciones que el jugador va juntando para una combinada |
| CI (integración continua) | Compilar y pasar las pruebas automáticamente en cada cambio |
| Combinada | Apuesta con selecciones de varios partidos; se gana si se aciertan todas |
| Commit | Un cambio guardado en Git, con su descripción y su autor |
| Criterio de aceptación | Condición que tiene que cumplirse para dar una historia por terminada (Dado / Cuando / Entonces) |
| CSRF | Ataque en el que otra web envía un formulario en tu nombre; se evita con un token |
| Cuota | Número por el que se multiplica el importe si se acierta |
| Entidad | Clase Java que corresponde a una tabla |
| Flyway | Herramienta que aplica en orden los scripts de la base de datos |
| Issue | Tarea, historia o fallo apuntado en GitHub |
| JPA / Hibernate | Traducción automática entre objetos Java y tablas |
| Margen de la casa | Lo que se queda la casa a la larga (1,07 → 6,5 %) |
| Mercado | Apuesta a largo plazo con varios candidatos |
| Migración | Script SQL numerado que cambia la estructura de la base de datos |
| MockMvc | Herramienta de pruebas que simula peticiones web sin navegador |
| MoSCoW | Priorización: Must, Should, Could, Won't |
| MVC | Modelo-Vista-Controlador: separar datos, presentación y control |
| MVP | Producto mínimo viable: lo imprescindible para que sirva |
| Perfil (Spring) | Conjunto de ajustes que se activa al arrancar (`compartir`, `nube`) |
| Pull request (PR) | Propuesta para juntar una rama con `main`, que se revisa antes |
| Rama | Copia de trabajo del código donde se hace un cambio sin tocar `main` |
| Repositorio (JPA) | Interfaz para buscar y guardar entidades |
| Selección | Un pronóstico dentro de una apuesta, con su cuota |
| Servicio | Clase con las reglas del negocio |
| Sesión | Memoria que el servidor guarda para cada usuario conectado |
| Sprint | Ciclo de trabajo de duración fija en Scrum |
| Squash | Fusionar un PR juntando todos sus commits en uno |
| Thymeleaf | Plantillas HTML que se rellenan con datos de Java |
| Transacción | Grupo de cambios que se hace entero o no se hace |
| Trazabilidad | Enlazar cada requisito con la prueba que lo comprueba |
| Velocidad | Puntos de historia terminados por sprint |
| XSS | Ataque que mete código en una página a través de un texto |
