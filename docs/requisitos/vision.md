# Visión del producto

## Problema / oportunidad
A los aficionados al deporte les gusta pronosticar resultados, pero las casas de apuestas implican dinero real y riesgos legales y de adicción.
Queremos una plataforma que ofrezca la experiencia de una casa de apuestas digital **sin dinero real**.

## Usuarios objetivo
- **Apostante**: usuario registrado que consulta eventos, apuesta con saldo ficticio y revisa su historial.
- **Administrador**: gestiona eventos, cuotas y resultados.
- **Visitante**: consulta eventos y estadísticas sin registrarse.

## Funcionalidades principales (de la propuesta enviada al profesor)
1. **Apuestas sobre eventos deportivos variados**, con moneda ficticia.
2. **Apuestas combinadas** creadas por el usuario. El sistema calcula el multiplicador total
   (con cuotas decimales, el producto de las cuotas de cada selección).
3. **Banco de estadísticas**: evolución de los equipos (resultados recientes, rachas, clasificación…) para consultar antes de apostar.

## Fuera de alcance
- Dinero real, pagos o cualquier tipo de canje.
- Apuestas en directo en tiempo real (posible ampliación futura).

## Preguntas abiertas
- ¿De dónde salen los datos de eventos y estadísticas? (API externa gratuita, datos simulados o carga manual por el admin)
- ¿Cómo se fijan las cuotas? (manuales, a partir de una API o calculadas con las estadísticas)
- ¿Qué deportes entran en la primera versión?
